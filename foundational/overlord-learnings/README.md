## Purpose

This directory serves as a knowledge base for:
1. **Improving Overlord prompts** - Understanding what worked and what didn't
2. **Enhancing startup capabilities** - Learning from challenges and resolutions
3. **Documenting decisions** - Why certain approaches were chosen
4. **Capturing feedback** - User guidance that shaped the system
5. **Episodic memory** - Critical learning moments stored in MCP

## Key Insights

1. **Workflow documents are requirements, not suggestions**
2. **Interactive validation is essential** - Never skip collaborative phases
3. **Document emphasis must be matched** - Verify understanding
4. **Episodic memory exists but underutilized** - Should be actively applied
5. **Practical scripts are essential** - Make workflows usable
6. **Communication patterns need documentation** - Explicit instructions required
